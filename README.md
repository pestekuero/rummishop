# RummiShop — demo web

Web estática responsive (HTML, CSS y JavaScript). No necesita Node, backend ni dependencias.

## Probar en local
Abre `index.html` en un navegador.

## Publicar gratis en Cloudflare Pages
1. Entra en https://dash.cloudflare.com/ y crea una cuenta gratuita si no tienes una.
2. Ve a Workers & Pages → Create application → Pages → Direct Upload.
3. Pon un nombre al proyecto y sube el ZIP de esta demo (o la carpeta descomprimida).
4. Pulsa Deploy. Cloudflare te dará una dirección `*.pages.dev` para compartir.

La demo solo funciona en el navegador: no guarda pedidos en servidor, no procesa pagos y no envía datos.
